Package: com.aistudio.zipspeed.zskt • Version 75.0.0 • Updated 26 September 2026

This policy describes the current v75 build. If Ads, Billing, accounts, new permissions, or new measurement providers are added later, this policy and Google Play Data Safety information must be updated before release.

ภาษาไทย

ZIPSPEED เป็นแอปทดสอบคุณภาพอินเทอร์เน็ตโดยไม่ต้องสร้างบัญชี แอปไม่สร้างค่าความเร็ว ตำแหน่ง หรือสถานะเครือข่ายปลอม

ข้อมูลที่ใช้ในการทดสอบ

  • แอปส่งคำขอดาวน์โหลด อัปโหลด และ HTTP latency probe ไปยังเซิร์ฟเวอร์ที่เปิดใช้งานใน Server Directory ปัจจุบันใช้ Cloudflare Network Quality endpoint
  • คำขออินเทอร์เน็ตย่อมเปิดเผย IP สาธารณะต่อผู้ให้บริการปลายทางตามธรรมชาติของการเชื่อมต่อ
  • แอปอ่านค่าที่เซิร์ฟเวอร์รายงาน เช่น IP สาธารณะ รหัส Edge และประเทศ เพื่อแสดงสถานะเครือข่าย โดยไม่สร้างพิกัดศูนย์ข้อมูลขึ้นเอง
  • หาก ISP/ASN หรือข้อมูลอื่นไม่มีแหล่งที่ตรวจสอบได้ แอปจะแสดง -- แทนการคาดเดา

ข้อมูลที่เก็บบนอุปกรณ์

  • การตั้งค่าของผู้ใช้เก็บใน app-local storage
  • ประวัติผลทดสอบสูงสุด 20 รายการ
  • เหตุการณ์ Monitor สูงสุด 50 รายการ
  • History เก็บค่าการวัด เช่น download/upload, idle/loaded latency, jitter, payload, profile/connection และ server ID
  • IP, ประเทศ, Edge code และ ISP ไม่ถูกเก็บไว้ใน History

การแชร์

ผลทดสอบถูกแชร์เฉพาะเมื่อผู้ใช้กด Share เอง ผ่านระบบ Share/Clipboard ของอุปกรณ์

SDK / บัญชี / โฆษณา / การชำระเงิน

build v75 ปัจจุบันไม่มีระบบบัญชีผู้ใช้ ไม่มี Ads SDK ไม่มี Firebase Analytics SDK และไม่มี Billing SDK แอปจึงไม่ใช้ Advertising ID สำหรับโฆษณาใน build นี้

สิทธิ์ Android

แอปใช้เฉพาะ INTERNET และ ACCESS_NETWORK_STATE ไม่มีสิทธิ์กล้อง ไมโครโฟน รายชื่อ หรือ Location permission ใน build ปัจจุบัน

ความปลอดภัย

การทดสอบเครือข่ายใช้ HTTPS, Android cleartext traffic ถูกปิด และ WebView mixed content ถูกปิด

การลบและระยะเวลาเก็บ

ผู้ใช้ลบ History และ Monitor log ได้ในแอป ข้อมูล local ทั้งหมดสามารถลบได้ด้วยการล้างข้อมูลแอปหรือถอนการติดตั้ง รายการที่เกินขีดจำกัดจะถูกตัดออกอัตโนมัติ

ผู้ให้บริการภายนอก

measurement endpoint ปัจจุบันดำเนินการโดย Cloudflare การประมวลผลฝั่ง Cloudflare อยู่ภายใต้นโยบายและเงื่อนไขของ Cloudflare ซึ่งแยกจากแอป ZIPSPEED

English

ZIPSPEED is an Internet quality measurement app that does not require an account. It does not fabricate speed, location, or network-status values.

Measurement data

  • The app sends download, upload, and HTTP latency probes to enabled endpoints in its Server Directory. The current provider is Cloudflare Network Quality.
  • Internet requests inherently disclose the device's public IP address to the destination service.
  • The app displays server-reported public IP, edge code, and country. It does not invent physical datacenter coordinates.
  • Unavailable ISP/ASN or other unverified fields are shown as --.

Local storage

Settings, up to 20 test-history entries, and up to 50 Monitor events are stored locally. History contains measurement results but does not store public IP, country, edge code, or ISP.

Sharing

Results are shared only after user action through the device Share/Clipboard flow.

Current SDK and permission state

Version 75 contains no account system, Ads SDK, Firebase Analytics SDK, or Billing SDK. Android permissions are limited to INTERNET and ACCESS_NETWORK_STATE; camera, microphone, contacts, and location permissions are not requested.

Security and deletion

Measurement traffic uses HTTPS; Android cleartext traffic and WebView mixed content are disabled. Users can clear History and Monitor logs in-app, or remove all local app data by clearing storage or uninstalling.

Third-party provider

The current measurement endpoint is operated by Cloudflare and is subject to Cloudflare's own policies and terms.
